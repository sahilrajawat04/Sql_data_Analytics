#  SQL Data Analytics Portfolio

A collection of production-grade SQL queries solving real-world business problems across Sales, Marketing, Supply Chain, and HR Analytics using MySQL.

---

## Business Scenarios Solved

* **`01_vip_customer_segmentation.sql`**  
  * **Goal:** Identifies high-value customers for targeted loyalty campaigns.  
  * **Skills:** `INNER JOIN`, `GROUP BY`, `HAVING` filters.

* **`02_top_performing_products.sql`**  
  * **Goal:** Tracks top revenue-generating inventory items to optimize stock.  
  * **Skills:** Multi-table joins, Data Aggregation (`SUM`), `ORDER BY`.

* **`03_regional_employee_ranking.sql`**  
  * **Goal:** Ranks regional sales performance to determine bonuses.  
  * **Skills:** Window Functions (`DENSE_RANK() OVER (PARTITION BY...)`).

* **`04_shipping_latency_analysis.sql`**  
  * **Goal:** Measures carrier efficiency and tracks late warehouse shipments.  
  * **Skills:** Date manipulation (`DATEDIFF`), Conditional Aggregation (`CASE WHEN`).

---

## 🛠️ Core Tech Stack & Competencies
* **Database Engine:** MySQL
* **Key Skills:** Advanced Joins • Data Aggregation • Window Functions • Conditional Logic • Business Metric Tracking
